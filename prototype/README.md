# Guardian UI prototype

设计原型（HTML + 本地 `charts.js`，无构建依赖、无需联网取图表库）。直接在浏览器打开 `index.html`。

## 可交互

- 右下角两个按钮：切换 **中文 / English**、**深色 / 浅色**。
- 顶部菜单栏 `文件 / 守护 / 视图 / 帮助` 可点击展开；视图菜单内含语言与主题子菜单。

## 设计方向

- 风格：`data-terminal`（深色监控台），seed `1562101498`。来自对长时间驻留的监控类界面的研究：
  深色中性底、信息按明度分层、颜色只用在数据与状态上、选中态用 1px 强调线，而不是彩色胶囊。
- 配色：唯一强调色是蓝色 1px 线与选中标记；绿/红/琥珀只用于运行中/异常/暂停状态。
- 字体：Public Sans（正文）+ JetBrains Mono（数字与轴刻度，数字等宽对齐）。
- "本产品独有"的元素：**重启脉冲（Restart pulse）** —— 每个守护项一条泳道，
  在时间轴上标出重启事件，异常密集点用红色高亮。这是通用仪表盘模板不会有的、
  只属于"进程守护"这件事的视图。
- 图表化显示（用 `charts.js` 从数据画 SVG，非图表库默认样式）：
  - **重启趋势**：最近 12 小时每小时重启次数折线图，带"14 时密集重启"标注；
  - **运行时健康度**：在线时长占比环图 + 在线/重启中/离线明细 + 一句发现；
  - 图表随中英文切换重绘，配色随明暗主题切换。
- 界面局部支持浅色主题，配色为同一套语义在浅色下的映射。

## 原型内的数据

示例进程名（SyncService / ReportAgent / EdgeWorker / LegacyBridge / QrScan）和时间、
重启次数均为**演示数据**，用于呈现密度与状态，实际实现时从守护引擎读取真实数据。
